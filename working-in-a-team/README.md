# Working in a team

A discussion-lead session on how to work well in a team and play well with others.

## Overview

- Team Dynamics
- Distributed teams
- Pair programming
- Mobbing

## Timings

- This session is timetabled for 1 block at 1.5 hrs
- The exercises for this session (done in breakouts) are also included in that time

## Assessments

To check the learner progress in this session we have:

- Discussions throughout
- Breakouts with discussions

## Prep

- Create the session files (pdf and zip) using `make generate-session-files f=module_name`
- Review the slides and exercises

## Session

- Run the presentation.
- The exercise at the end of the session is specific to the progress they are making to their mini-project.
    - It helps to make some suggestions for new features they can include on their app or they can  attempt one of the goals set in the mini project
