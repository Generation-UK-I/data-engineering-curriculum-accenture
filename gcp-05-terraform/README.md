## Prep

- Make a pdf of `exercises/terraform-exercise.md`
- Create the session files (pdf and zip) using `make generate-session-files f=module_name`
- Review the slides and exercises

## Session

- Give out the `exercises/terraform-exercise.pdf` you made above
- Run the presentation
- When it comes to the Demos, make the learners are not copying along, they can have a go later
- When it comes to the exercise time, make sure all learners are progressing ok
