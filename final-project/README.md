# Final Project

This presentation contains the context for the final project, usually presented by one of our BA colleagues to the cohorts:

- The first half goes through the concepts and artefacts
- The brief is introduced in the middle
- The second half gets the teams to produce the artefacts

This session is unusual in that:

- The majority is delivered from a powerpoint deck
- Only the Project Brief is delivered from this repo using reveal

## Review Final project documentation

The session is primarily delivered from a powerpoint deck - see the `Prep (Whole session)` section below.

Any questions you might have about the technical aspects and setup of the final project as an instructor are laid out in the [DE Final Project Google doc](https://docs.google.com/document/d/1GQ6avVo6iwYYs3LC7qPPmIIszPKaMyenuO8VvMjk2yM/edit#)

- This lives in folder [Google Drive/Shared drives/IW_(TD) Academy (Internal)/(02) Academy Programmes/Data Engineering Academy - Common](https://drive.google.com/drive/folders/1SeCRBDOR5FphPo1WyDcudvO3pzl-cEYC)

## Overview (Intro to Inception Slides Presentation)

- Understand what an Inception is
- Build an elevator pitch
- Agree importance
- Agree scope
- Define the scope
- Define success
- The approach
- The extended team
- Breakdown the project
- Estimation and risk
- Epic roadmap

## Overview (Project brief MD/PDF)

- Background for the project
- Discussion of expected solution
- Ways of working and approach
- The role of the instructor

## Timings (Whole session)

- This session is timetabled for 3 blocks at 1.5 hrs each, i.e. 0.75  elapsed training days

## Assessments (Whole session)

Each Team will collaboratively produce project artefacts including

- Elevator Pitch
- Importance check
- Scope check
- Success criteria
- Initial project Breakdown (MOSCOW)
- Initial Risk register
