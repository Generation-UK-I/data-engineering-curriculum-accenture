# Mini Project

Over the course of six weeks during the first-half of the programme, learners will be expected to produce a small app to run in the terminal. This project aims to closely mirror the curriculum allowing learners to grasp a number of concepts or skills during the week and quickly apply these to their project to further cement their learning.

## Breakdowns

The weekly goals are found in the [`./exercises/*.md`](./exercises/) files.

These contain a step-by-tep narrative as well as a breakdown of user stories, tech-spec, and goals, as well as some pseudo code to help them along their way.

- **Core Goals** are the minimum requirements expected from each learner _note: unmarked_
- **Stretch Goals** are intended for those looking for a greater challenge
- **Bonus Goals** are intended for the exceptional learners

Be sure to discuss these weekly and distribute as PDFs to the learners.

## Session

Deliver the top-level `mini-project.md` presentation early in the first week to introduce learners to the requirements and specifications of the project.

Hand this same presentation out as a pdf to learners for their own reference.
