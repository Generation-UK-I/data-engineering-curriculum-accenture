# Data-Streams

In this module, we will introduce learners to a number of new concepts related to data streaming. We will cover what a data stream is, and what it means to 'do data streaming'. We will look at batch processing as a counterpoint to data streaming, and cover their respective use cases. We will then start to look at some of the things to consider around data streaming architecture, which leads into a look at the GCP solutions - Dataflow.
