## Boris bikes

This directory contains four Python files which can make up a simple code-along style session to go through with learners. The sessions models a simple 'boris bikes' scenario, where you have two classes - a bike and a docking station, and you can just do some very simple actions on initialised objects - docking a bike at a station or undocking it.

The purpose is to demonstrate a little on how OOP works, and the concepts of instantiating concrete objects from your classes.

It is also an ideal exercise to demonstrate TDD - there are some simple tests included in the two test files, and these are easy to introduce before the code itself, to demonstrate a TDD approach.

Suggestion if running this is to just understand the complete example here, and keep it as a reference, then build up a new version of the model as a live demo.

There is also an additional file here - `airport_user_stories.txt` - this can be used to set the learners an additional exercise to try.
