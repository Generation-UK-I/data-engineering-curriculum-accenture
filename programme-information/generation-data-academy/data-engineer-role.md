# Entry-level Data Engineering role - core skills and knowledge

The key aim of the Generation / Infinity Works Data Engineering programme is to help graduates from the programme secure a role as an entry-level Data Engineer. This document outlines the core skills and knowledge we feel that a person would need in order to be able to successfully take on this role.

## Technical skills and knowledge:

- Ability to programme at a basic level in a data-engineering specific language such as Python
- Ability to perform basic queries and CRUD operations in Structured Query Language (SQL)
- SQL database design and basic operations (creating databases, tables, data itself etc.)
- Fundamentals of programming concepts that apply in any programming language (but with data engineering specific language such as Python most relevant)
- The ETL / ELT pipeline concept, understanding the benefits and limitations of both
- Good understanding of the importance of data cleansing
- Good grasp of command line concepts (Unix or Windows) to help speed up actions or automate work
- Basic understanding of big data
- Understanding of different data structures and file structures
- Large scale database concepts such as data warehousing and data lakes
- Basic understanding of data normalisation
- Awareness of other database constructs (document, key-value, graph etc.)
- Basic understanding or awareness of data visualisation tools and techniques
- Basic understanding or awareness of APIs, their benefits and limitations
- Basic understanding of cloud computing
- Testing concepts (Unit testing, Integration testing, UAT, system testing etc.)
- Potentially basic understanding or awareness of deployment concepts and techniques
- Basic understanding of data security, including database user access controls, PII and GDPR
- Good understanding of source control
- Ability to use an IDE such as Visual Studio Code or PyCharm

### Soft skills and knowledge

- Working in a team
- Working independently
- Being able to give and receive feedback maturely
- How to tackle a problem with no obvious solution
- How to apply a method of learning gained in one area (e.g. learning Python) to another (e.g. learning Snowflake)

## Role definition from Generation

Outlined below are the goals, mindsets and behaviours for an entry-level Data Engineer that the programme aims to teach

### Performance Goals (Graduates will be able to...)

- Drive value for the organization and its clients by having a thorough understanding of data, its purpose, and its usage.
- Design and build data platforms to collect, store, and retrieve raw data.
- Build data pipelines effectively using ELT.
- Apply structured problem solving techniques to determine solutions.
- Learn new technical skills to improve performance and stay current in the industry.
- Effectively communicate and collaborate with internal and external stakeholders.

### Behavioral Skills & Mindsets

Mindsets are orientations that participants need for success on the job, and beyond in life. All Generation programs develop four critical mindsets--personal responsibility, persistence, growth mindset, and future orientation--by training participants to reflect on and apply them on the job and in life. Below are the Generation mindsets, and a one sentence definition next to each that illustrates the mindset in the role.

| Generation Mindset | Definition |
| ------------------ | ---------- |
| Personal Responsibility | I take ownership over my work and decisions. I work hard, keep commitments, and don't make excuses. |
| Persistence | I do not give up in the face of challenges or after I have made a mistake. |
| Growth Mindset | I believe I can learn and improve over time with practice. |
| Future Orientation | I set goals for the future, understand how my actions will help me achieve them, and frequently check my progress. |

Each Generation program also prioritises identifies three to four behavioral skills, or attitudes that permeate and influence one's work and performance, that are critical for success in the role. We hone in on which behavioral skills are most critical for the role through the activity mapping process--in the interviews conducted and identifying what makes high performers successful.  Below are the behavioral skills selected for the UK Junior Data Engineer program, and a one sentence definition next to each that illustrates the behavioral skill in the role.

| Behavioral Skills | Definition |
| ----------------- | ---------- |
| Teamwork | I communicate and collaborate with my team, ask for help when I need it, and offer them support. |
| Communication | I am able to convey my message clearly to different types of people using a variety of tools to receive and spread information. |
| Orientation to Detail | I maintain a close eye for detail when executing tasks so they are completed with precise accuracy and thoughtfulness. |
| Proactiveness | I take initiative in my work, anticipate situations, and find ways to contribute to the team. |
