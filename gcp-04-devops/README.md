# DevOps

This module introduces learners to the concept of DevOps, which is a set of practices that combines software development (Dev) and IT operations (Ops).

We introduce learners to the overall concept of DevOps and it's philosophies. CI/CD and IaC are the two main topics that are discussed thereafter.
