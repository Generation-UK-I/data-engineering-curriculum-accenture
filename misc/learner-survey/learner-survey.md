We have made this short survey, which will ask you a few questions about things like your favourite parts of the course, your favourite ways of working etc.

## Questions

1. Broadly speaking, the list of modules above, which we have covered on this course to date, can be summarised in the below list of broad topics. From 1 - 5 (with '1' being not enjoyable and '5' being very enjoyable), how much did you enjoy learning about each of the broad topics:
    - Software engineering (e.g. intro to programming modules, testing modules, OOP, APIs)
    - Data engineering (e.g. data persistence, databases, ETL modules, visualisation)
    - Infrastructure (e.g. Docker, AWS, CI/CD)
    - Operations (e.g. Unix shell, shell scripting, security guest modules, monitoring)
    - Ways of working (e.g. Agile, DevOps, Working in Teams, Project Inception)
1. From the list of modules above, please select ONE module which you would say was your favourite, and write a sentence or two on why it is your favourite
1. What is the one TECHNICAL skill you have picked up during the course that you are most looking forward to using in a Sainsbury's team?
1. What is the one NON-TECHNICAL skill you have picked up during the course that you are most looking forward to using in a Sainsbury's team?
1. What is something you have implemented in your project (either mini project or final project) which you are particularly proud of?
1. For the below activities, please indicate how much of each activity you would ideally like your first project to involve? (For the avoidance of doubt, you can assign any number from 1-5 for each activity, and repeating the same number is allowed for multiple activities. The scale is from '5' meaning 'I would like to do a lot of this', down to '1' meaning 'I would prefer not to do a lot of this')
    - Writing code
    - Testing code
    - Running code
    - Debugging code/fixing errors
    - Writing/building/configuring infrastructure
    - Visualising data
    - Liaising with business contacts to determine technical requirements
1. Please place an X beside the statement below which you think most applies to you
    - I would prefer a role with a narrow focus so I start to build some deep expertise in a few areas
    - I would prefer a role with a broad focus so I start to build wide knowledge in a lot of areas
1. From 1 - 5 (with '1' being not enjoyable and '5' being very enjoyable), how much did you enjoy each of the following styles of working on your projects (if you didn't do a particular style at any point, just put an N/A for that style of working)
    - Working alone on my mini project
    - Working alone on the final project, but as part of a team all working on different tickets towards a shared goal
    - Pairing (as part of exercises or final project work)
    - Mobbing (as part of exercises or final project work)
1. Do you think you would prefer to work as part of a larger team, or a smaller team, and why?
1. What do you think is your optimal learning style (e.g. some ideas of learning styles would be - you learn well from reading theory, you learn by doing, you learn by seeing examples, you learn by discussing a concept, you learn by reflecting on a concept)?
