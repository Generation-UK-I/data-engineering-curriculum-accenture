## Pandas Introduction

This optional sessions aims to introduce learners to some of the basic concepts and functionality of the pandas library.

We tried out delivering it as an iPython notebook, as it allows for flexible and interactive execution of the code throughout.

The `pandas_intro.ipynb` document was prepared in advance and delivered as-is during the session, so it should be pretty much ready to deliver as-is. You will just need to ensure that you install `jupyterlab` via pip, and launch a jupyter notebook before running the session
