## Functional Testing Exercise

---

### Exercise

Let's consider all the different features and scenarios in your application.

- Create a testing tracker spreadsheet
- Design a number of test scenarios for your miniproject and write them down in a spreadsheet
- Think about:
    - Data Input Handling
    - Data Output
    - User Interface (UI)
    - Data Persistence
- Regroup after 15 mins

---

### Exercise (Part 2)

Pair up and test each others applications.

- Run through your partners test scenarios and record the results on their spreadsheet
- Once you have been through the prepared test scenarios let's explore!
- What more could you test?
- Record what you test and the results in the spreadsheets

---

### Discussion in your pairs

- Did you catch any regressions? If so, how did you make sure fixing those wouldn't introduce any further regressions?
- Are there any ways you could refactor your code to minimise regressions?
- What improvements would you make to this testing approach to make it more efficient and better at catching regressions?
