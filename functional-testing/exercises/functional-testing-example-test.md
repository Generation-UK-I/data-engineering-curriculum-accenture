### Examples of Functional Tests for Mini Project

Data Input Handling:

- What happens when you enter a null value?
- What about duplicates?
- What about quitting?

Data Output:

- Does the app return what you expect?
- Capitalized or lowercase?

UI:

- What happens when you enter a non-valid input?
- Can you navigate to the menu from anywhere?
- What about quitting?

Data Persistence:

- Does the file save and open from txt/csv correctly?
- Does new data append correctly?
- what about updating the file?
