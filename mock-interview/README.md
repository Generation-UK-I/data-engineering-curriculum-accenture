### Mock interview

We run mock interviews for the learners to prep them for what they might experience after the course. It is in two main halves - whiteboarding a recent project, and a live coding exercise.

This session provides the learners with all the information they need to be successful in their mock interviews. It should be delivered in the final few weeks of the program.

The learners will be given access to the Academy tech test repository in this lecture, so try not to deliver it too early in the program.

The mock interviews themselves are not part of _this_ session, this session is the prep.

## Exercises in this session:

Within this session are further practices for the mock interviews, which are held separately.

- Whiteboarding exercise: Using Zoom rooms, split the learners into random pairs and have them spend ten minutes each talking about and visualising a project of their choice. Once the time is up, ask for a volunteer to share out to the rest of the class and ask the class for feedback.

- Technical exercise: The learners must sign up for LeetCode and complete a simple programming problem. The goal here is to introduce the learners to LeetCode so they have a simple way to practice solving programming problems ahead of future interviews. Allocate 20 minutes to this exercise. Once the time is up, ask a learner to share their answer.
