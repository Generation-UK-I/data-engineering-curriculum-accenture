## Tableau

The Tableau module is designed to teach the learners how to use Tableau. It covers connecting data sources, building visualisations and dashboards. The learners should have Tableau open while the presentation is being delivered so they can follow along with the slides.

## Prerequisites:

All learners will need a working version of Tableau desktop installed on their machines.

## Overview

- Connecting to different sources
- Creating a Tableau data source
- Creating views in the Tableau workspace
- Creating Dashboards

## Timings

- This session is timetabled for X1 blocks at 1.5 hrs each
- The formative assessments occur during this and are included in that timing
- The exercises for this session (done in breakouts) are also included in that time
