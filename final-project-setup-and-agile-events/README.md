# Team Project Setup & Agile Events

## Objectives

- Arrange your teams weekly rituals
- Understand what a good standup is
- Understand what a good retrospective is
- Understand what a good Sprint Planning session is
- Have a project Document and/or Whiteboard with the outcomes of your Inception session in it
- Have a Git Repository with a README with a link to your project docs
- Have a GitHub Projects board
- Know what to do next

## Timing

About 1 block or 1.5 hrs.

## Prep

- Export the presentation to PDF and the zip for distribution using `make generate-session-files f=session_name`

## Session

This session should follow the [Team Project Inception](../project-inception/project-inception.md) all-morning session.

This session helps the Project Teams get up and running.

After it they should know what to do to get all these artifacts produced:

- A Team Project **document**, typically in Google Docs with the text outcomes of the "Team project Inception" session in it, i.e:
    - Elevator Pitch
    - Success Flexes (Scope, Budget, Time, Quality)
    - MoSCoW items
    - Success criteria (SMART goals)
    - Starting Project Breakdown
    - Starting Project Epics
    - Risk descriptions
    - Weekly Roadmap
    - Some teams may elect to do all this on the Team Whiteboard, as below
- A Team Project **whiteboard**, typically in MS WHiteboard, with the visual outcomes of the "Team project Inception" session in it, i.e:
    - Use <https://whiteboard.office.com/> as it's free
    - Sample story boards of screen flows
    - Sample wireframes of some screens
    - MoSCoW items (here or in above doc)
- A GitHub Projects Board
    - MoSCoW items and/or starting Epics entered in a Backlog Column as a starting point
- A GitHub repo in the IW-Academy org
    - Should have a README
    - README should have a title, a basic description and maybe the Team members names?
    - README should end up with links to the above docs
    - A License file
    - A `.gitignore` for Node projects
    - CDK critical ignores added to `.gitignore`, *because Security*.
